# Spindle 2.5.0

- Continue with Google or Apple: sign in or create an account without a password, on servers that offer it.
- While you type a description in the entry editor, Spindle offers ones you wrote before, also for each project's own description in a split. ↑ and ↓ pick one and Return takes it; the project and the split stay as they are. Needs macOS 15.
- The timer's suggestions show first what starts with what you typed, then what you wrote on the same project and what you use most.
- Spindle reads GitHub Copilot CLI logs too, beside Claude Code and Codex. Choose which agents it reads in Settings → General → Parallel work. If you already had agent logs on, Copilot starts off there.
- An entry changed on another device while this Mac was offline is no longer overwritten. "1 change to review" in the toolbar shows yours and theirs, and you keep one.
- Fixed "✦ 1 to review" beside today when the day had nothing to review.
