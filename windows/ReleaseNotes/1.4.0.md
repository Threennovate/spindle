- Ignore a repository you don't want in Spindle, such as a private project: choose Ignore repository beside No project in Settings → General → Parallel work → Linked repositories, or for a repository in a suggestion or the day's review. Its agent work no longer shows in the calendar, suggestions or untracked time, and the time you spent there isn't given to another project either. With activity sync on, nothing about it is sent; your other devices get only a hash of it, so they ignore it too. Settings lists ignored repositories, to stop ignoring one.
